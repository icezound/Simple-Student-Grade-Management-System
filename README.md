# Simple-Student-Grade-Management-System
在编写代码时，我将系统功能划分为多个模块，例如 menu 函数用于显示菜单，add 函数用于添加记录，showAll 函数用于显示所有记录等。这种模块化的设计使得代码结构清晰，便于理解和维护。例如，当需要修改某个功能时，我只需要找到对应的函数进行修改，而不需要改动其他部分的代码。这种编程方式让我感受到了代码组织的重要性。 在系统中，我使用了结构体 struct student 来存储学生的信息，包括学号、姓名、各科成绩、总成绩和原神等级等。结构体的使用使得数据的组织更加清晰，同时也方便了对数据的操作。例如，在排序功能中，我通过比较学生的总成绩 sum 来实现按成绩从高到低的排序。或者原神等级不合理或者等级过高会出现提醒标识，等级正常并且超过一定数值会有鼓励和奖励机制。
